# InterValue

A simple interval timer for iOS. No ads, no accounts, everything stays on your phone.

[Download on the App Store](https://apps.apple.com/il/app/intervalue/id6760939754)

## Build

Open `InterValue.xcodeproj` in Xcode and run. Requires iOS 26.2.
